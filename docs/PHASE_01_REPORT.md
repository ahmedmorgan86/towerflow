## التنفيذ

- إعادة استخدام org_id كحد مستقل لدفتر برج واحد؛ نفس المستخدم يدير عدة أبراج عبر عضويات مستقلة. ترفض قاعدة البيانات إضافة برج آخر إلى الدفتر نفسه. السجلات القديمة متعددة الأبراج تُحفظ وتُوقف كتاباتها المالية للمراجعة، دون توزيع تخميني.
- معالج برج مستقل يختار الدولة والعملة من قوائم مسماة، ويبدأ بخزائن صفرية؛ يدعم توليد أرقام الشقق أو إدخال توزيع مختلف للأدوار. الإنشاء ذري ويمنع تكرار الشقق.
- فصل اعتماد المصروف عن دفعه: الاعتماد يسجل مصروفًا والتزامًا، والدفع يسجل تخفيض الالتزام والخزينة. يُحفظ التاريخ النقدي القديم دون إعادة ترحيل.
- خزائن وبنوك ومحافظ مستقلة؛ تحويل داخل البرج فقط؛ دفع جزئي؛ مراجع تمنع تكرار الدفع والتحويل وتكشف تغير الطلب؛ رفض الرصيد غير الكافي.
- حماية هوية الحساب بعد الترحيل، وقفل العملة بعد بدء القيود، وأرشفة للقراءة وإعادة تفعيل موثقة.
- لوحة تعرض النقدية والمعتمد والمدفوع وغير المدفوع منفصلة، كلها تراكمية للبرج المحدد. التقارير التفصيلية تعرض المدفوع والمتبقي.
- شاشات Android لإنشاء البرج والخزائن والتحويل والدفع تستخدم نفس خدمات الويب وقواعدها. بناء Debug وLint نجحا؛ لم يُختبر جهاز فعلي.
